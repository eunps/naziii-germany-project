Список использованных источников

Ниже приведён перечень материалов, на основе которых подготовлен проект. Источники подобраны с учётом требований к достоверности и академической нейтральности.

  1. Учебник по истории России и мира для 10–11 классов (базовый уровень). Раздел о межвоенном периоде и Второй мировой войне.
  2. Документы по истории Германии 1919–1945 гг. (фрагменты законов, программные тексты, официальные заявления). Использованы выдержки из открытых архивных публикаций.
  3. Материалы образовательных порталов, посвящённых истории XX века (текстовые обзоры, хронологии, справочные статьи). Использовались только верифицированные материалы без оценочных и пропагандистских формулировок.
  4. Статистические данные по экономике и демографии Германии в 1920–1930-е годы (уровень безработицы, инфляция, динамика промышленного производства) из открытых справочных сборников.
  5. Результаты опроса учащихся (анкета из 5 вопросов, выборка — 25 респондентов). Обработка данных выполнена вручную, выводы сформулированы на основе процентного распределения ответов.

Методология работы с источниками

При подготовке проекта соблюдались следующие принципы:

  • Достоверность: использовались только опубликованные и доступные для проверки материалы.
  • Нейтральность: избегались источники с выраженной пропагандистской или эмоционально окрашенной подачей.
  • Проверяемость: все факты, приводимые в теории и хронологии, соотносились минимум с двумя независимыми источниками.
  • Учебная уместность: формулировки адаптированы для школьного уровня, без избыточной терминологии, но с сохранением исторической точности.
